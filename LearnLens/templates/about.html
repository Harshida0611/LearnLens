ABOUT LEARNLENS

Making Student Data Meaningful.

LearnLens is a Student Performance Prediction System designed to use academic information and machine learning to provide useful performance insights.

Our Purpose

Students generate a large amount of academic information through attendance, assignments, tests and previous examinations.

LearnLens brings these factors together and uses data analysis and machine learning to help understand expected student performance.

The goal is to make performance information easier to understand and support better academic decisions.
